# Reset Button

Date: August 4, 2026
Notes: The "Preset Orbit" Button
• What it does: Instantly teleports the rocket to a perfect starting spot 200 pixels away from the planet.
• How it helps: It uses the space physics formula $v = \sqrt{\frac{M}{r}}
$ to calculate the exact starting speed needed for a circular orbit. It saves the user manually trying to get back to the starting orbit  speed and orbit shape.
